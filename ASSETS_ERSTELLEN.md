# 🎨 Assets Erstellen - SO EINFACH

## 1️⃣ Datei öffnen

```bash
# Im Browser öffnen:
open GENERATE_ASSETS.html

# Oder doppelklick auf die Datei
```

## 2️⃣ Button klicken

Klicke auf **"Alle Assets Generieren"**

Es werden automatisch 4 Dateien heruntergeladen:
- ✅ icon.png
- ✅ adaptive-icon.png
- ✅ splash.png
- ✅ favicon.png

## 3️⃣ Dateien verschieben

Verschiebe alle 4 heruntergeladenen Dateien in den Ordner:
```
assets/
```

## 4️⃣ Fertig!

Die App ist jetzt bereit zum Starten:
```bash
npm install
npm start
```

---

## Alle Assets in EINER Datei

Die Datei `GENERATE_ASSETS.html` enthält:
- Kompletten Icon-Generator
- Schöne Preview
- Automatischer Download aller Assets
- Fortschrittsanzeige

**Kein npm install nötig, kein Node.js, nur Browser öffnen!**
